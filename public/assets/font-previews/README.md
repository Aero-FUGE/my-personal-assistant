# Preview-only font subsets

These small WOFF2 files contain only the text used on the font comparison page.
They are not the application's final UI fonts and are not desktop installers.
Internal subset family names are AssistantPreviewSerif and AssistantPreviewWenkai.

- serif.woff2: derived from Adobe Source Han Serif SC Regular, official repository
  https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese
  License and attribution: serif-OFL.txt.
- wenkai.woff2: derived from LXGW WenKai Regular v1.530, official release
  https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530
  License and attribution: wenkai-OFL.txt.

Subsets are generated by scripts/prepare-font-previews.py at the repository root.
The final typeface choice, production Unicode coverage/subsetting strategy and
consistent cross-device typography remain subject to user approval.
