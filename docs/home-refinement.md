# 第一轮首页精修

本轮只修改首页组件、首页 CSS 和 Today 的入口衔接，人物与美术源图保持不变；其他页面的布局、任务选择规则、数据库结构及公共业务服务没有修改。

## 布局调整

- 人物区域改为两行网格：第一行是随视口高度调整的立绘展示空间，第二行是内容驱动的对话框。立绘图仍按原始比例显示，仅独立立绘视窗遮住下半身并在对话框后渐隐；人物面部完整。没有给整页加负 margin，也没有裁切任务或锁定页面滚动。
- 对话框保留原素材的顶部／中段／底部切片，顶部和花卉装饰依然等比。缩减内边距和文字间距，聊天入口位于左侧，避免右下花卉挡字。内容增多时容器自然增高。
- 任务面板随展示区缩短自然上移，合并标题牌下方的状态和任务管理入口占用空间，缩减任务标题、预计时间与主操作的间距。长任务标题和描述完整换行，必要时正常滚动；所有操作始终可滚动到达。

## 信息与入口

对话区只承担问候及交流引导。空状态时使用“今天的安排已经处理妥当，要为您安排新的计划吗？”；任务面板只显示“今日暂无待办”和“安排新任务”。“全部任务”入口始终保留。

无任务的主按钮直接打开首页的新建任务表单；保存后从真实 IndexedDB 数据重新选取首要任务。有任务时，“开始执行”通过原服务设置为进行中并立即打开该任务详情／编辑表单；“继续执行”同样直接打开该任务。完成、延期、编辑和项目关联等原有数据逻辑保留。

## 验收

生产构建通过，15 项业务测试通过，Chromium / WebKit 回归覆盖 16 项用例，均已验证通过（其中原生活页异步刷新用例补充保存反馈等待后单独复测通过）。新增检查在 320 / 390 / 430 × 844px 下验证常规任务的完整标题、预计时间和主操作位于固定底部导航上方，并验证空状态直接新建、执行后进入详情、对话框高度、人物面部与原始比例、背景全宽、长标题滚动及全部导航。

首屏可容纳内容仍取决于实际屏幕高度、字体缩放和任务文本长度；极长标题或描述不截断，使用正常页面滚动。浏览器模拟不替代物理 iPhone 真机验收。
