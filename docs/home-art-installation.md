## 裁切和面板

[裁切脚本](../scripts/crop-home-art.py) 只执行矩形无损裁切，使用 Pillow，不是应用运行时依赖。主／次按钮分别输出默认、按下、禁用图，位于原 buttons 目录，文件名为 `buttons-source-primary-default.png` 等六张。裁切保留原透明通道、完整金边及可分离的阴影，排除了说明文字和其他图标。没有重新绘图或用色键抠图。

对话框与任务框各输出 top / middle / bottom 三张切片。顶部、底部按宽度等比缩放；中段仅包含直边和无文字留白，允许延长，从而保留雕花、姓名牌、花朵、书籍、钢笔的比例。姓名、问候、任务标题、状态及按钮文字均为真实 HTML。

## 白边修复及分层

原背景位于有 max-width 的 `.home-page` 内，外部 main 同时有 38px/44px（手机为 26px/18px）内边距，底部还有独立 footer，所以图像只覆盖内部矩形，露出默认 body 的米白色。

现在 AppShell 按首页路由挂载独立的背景层和 `.shell-home`。背景直接位于 shell 下，fixed inset:0，等比 cover，居中靠上，pointer-events:none；不是 iOS 的 background-attachment:fixed。该层不受 main、内容卡片、圆角或 max-width 限制。首页 main 移除外层宽度约束和内边距，内容自己保留 12–18px 内边距及桌面阅读宽度。

首页 body / html 的底色、顶部导航、底部导航及侧栏仅在 `.shell-home` 存在时切换为紫金色，退出首页恢复其他页面原样。背景、人物、对话框和任务面板分别独立布局；人物和所有装饰切片不接收触摸，不改变页面滚动容器。底部仍保留原安全区域和可滚动留白。

所有动态图片地址、切片及按钮 CSS 变量都由 `import.meta.env.BASE_URL` 构造，保留仓库子路径支持。人物加载失败明确显示资源路径错误，不静默恢复占位人物。

## 功能保护与测试

未修改数据库结构、任务选择算法、TaskService、项目、聊天、提醒及部署配置。全局 GameButton 仍为 HTML button；首页通过专用 class 设置三态素材。主按钮开始／继续执行、完成、延期、编辑与全部任务入口保持原事件。

检查包括：生产构建，15 项业务测试，以及 Chromium / WebKit 下原有功能回归和新增首页美术检查；320 / 390 / 430px 的背景视口边界、无横向溢出、立绘真实加载及比例、脸部未被对话框覆盖、全部导航、长标题、按钮及本地任务数据保留。新增的背景边界断言已从旧的内容矩形调整为整个视口。
